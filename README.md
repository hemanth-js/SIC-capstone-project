# SIC Capstone Project

FindIt is a campus lost-and-found matcher built as a single-page web app.

## Run

Open `index.html` in a modern browser. Three.js and Google Fonts are loaded from CDNs, so those visual assets need an internet connection. App reports and account data are stored locally in the browser.

## Demo accounts

- Student: `student@college.edu` / `Demo@1234`
- Staff: `admin@college.edu` / `Admin@1234`

Staff registration uses demo PIN `1234`.

## Notes

This project uses front-end-only authentication and browser storage. It is intended as a capstone demo, not as production identity or access control.
